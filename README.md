# Data Science Assignments 📊

This repository contains my data science projects and assignments, focusing on data engineering, statistical analysis, and machine learning models.

## Repository Contents

### 📂 [HW1: History of Rock EDA](./History%20of%20Rock%20EDA/)
An end-to-end Exploratory Data Analysis of Spotify's "History of Rock (1950-2020)" dataset. 
* **Focus:** Feature engineering, handling algorithmic biases (e.g., API failure placeholders, time-dependency of remastered tracks), and advanced categorical analysis.
* **Key Discovery:** Identified an algorithmic breakdown in Spotify's audio analysis model regarding complex/asymmetric time signatures (e.g., Pink Floyd's "Money").
* **Tech Stack:** Python, Pandas, Seaborn, Matplotlib.

### 📂 [HW2: Regression & Classification Error Analysis](./Voice%20Error%20Analysis/)
A systematic investigation of model failure patterns using the "Acoustic Features of Voice" dataset[cite: 1]. 
*   **Focus:** Moving beyond basic accuracy to diagnose heteroscedasticity, isolate extreme errors, evaluate threshold sensitivity, and compare linear assumptions against tree-based ensembles[cite: 1].
*   **Key Discovery:** Models systematically fail at hard biological boundaries (overlapping pitch ranges between genders) where acoustic traits naturally blur, proving that non-linear tree ensembles are required to map hidden subpopulations[cite: 1]. 
*   **Tech Stack:** Python, Pandas, Scikit-Learn, Seaborn, Matplotlib.
